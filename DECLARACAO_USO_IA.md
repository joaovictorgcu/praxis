# Declaração de Uso de Inteligência Artificial

## Projeto: PRAXIS - Sistema de Gestão Jurídica

**Data**: 10 de outubro de 2026

---

## Escopo do Uso de IA

Este projeto foi desenvolvido com auxílio de **GitHub Copilot** (Claude Haiku 4.5), uma ferramenta de IA generativa para código.

### O que foi feito COM IA:

✅ **Geração de código estrutural**
- Implementação de classes de domínio (Audiencia, Cliente, ParteContraria)
- Criação de repositories JPA
- Implementação de services e controllers REST
- DTOs e classes de transferência de dados

✅ **Sugestões de arquitetura**
- Estruturação em 6 camadas (Domain → Presentation)
- Padrões de design (DDD, Clean Architecture, SOLID)
- Organização de pacotes e convenções de nomenclatura

✅ **Geração de testes**
- Testes unitários com JUnit 5
- Steps de BDD com Cucumber
- Cenários em Gherkin (português)

✅ **Documentação**
- Comentários em código
- Documentação técnica (IMPLEMENTACAO.md, API_ENDPOINTS.md, etc)
- README e guias de uso

---

### O que foi feito SEM IA (Trabalho Manual):

✅ **Decisões de design**
- Escolha da arquitetura e padrões
- Definição da lógica de negócio
- Algoritmo de detecção de conflitos

✅ **Validação e testes**
- Verificação de compilação
- Execução de testes
- Validação de funcionalidades

✅ **Refinamento**
- Correção de erros e bugs
- Ajustes nas implementações
- Melhorias no código gerado

✅ **Integração**
- Conexão entre camadas
- Configuração do Spring Boot
- Setup do banco de dados H2

## Independência Acadêmica

Embora o código tenha sido gerado com auxílio de IA:

✅ **A lógica de negócio é original** - A detecção de conflitos de audiências foi concebida manualmente

✅ **A arquitetura é compreendida** - Todas as decisões de design podem ser justificadas e explicadas

✅ **O código foi validado** - Todos os testes foram executados e validados manualmente

✅ **A implementação foi supervisionada** - Cada componente foi revisado e ajustado conforme necessário
